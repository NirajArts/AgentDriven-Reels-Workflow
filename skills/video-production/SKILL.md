# Video production

Read root [AGENTS](../../AGENTS.md), HANDOFF and the active project status. No creative choices are preset. Establish topic, audience, format, language, visual direction, narration choice and scope from the user's request; ask only for material missing decisions.

Use [Workflow](../../Docs/Workflow.md). Create a project only after a video is requested, with the root `scripts/new_project.py`. Complete brief and research, write exact words and delivery intent, then seek the agreed script review before paid synthesis/full build. Keep setup, creative work and external actions distinct.

For narration, follow [Narration](../../Docs/Narration.md) and [Word timing](../../Docs/Word_Timing.md); for silent content use explicitly editorial timing. Never treat estimated word counts as measured timing.

Convert each line into an observable action and result using [Scene planning](../../Docs/Scene_Planning.md). Specify heading behavior, reading holds and handoffs. Build a short representative visual proof and extend the accepted direction rather than repeatedly redesigning accepted sections.

Inspect actual output and fix discrepancies before final export. Use [QA](../../Docs/QA_and_Export.md) and [Packaging](../../Docs/Packaging.md), record unavailable playback/listening honestly, and update status/handoff with exact artifact paths and the next action. A download CTA needs a tested deliverable and real delivery route. Local preparation is not publication.
