# Included skills

These are portable Markdown instructions for the agent working in this repository:

- [video-production](video-production/SKILL.md): brief, script, shot plan and end-to-end evidence.
- [effectcraft-production](effectcraft-production/SKILL.md): live native editing, visual QA and export.
- [audio-word-timing](audio-word-timing/SKILL.md): local independent transcription and timing review.

Ask your agent to read the relevant `SKILL.md` directly. AGENTS.md links them, so setup does not depend on a particular agent's skill auto-discovery. If your agent supports registered skills, follow its current installation instructions. Keep these folders in this repository: their document links resolve relative to this location. No third-party plugin skill or installer is bundled.
