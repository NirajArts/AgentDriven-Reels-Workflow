# EffectCraft production

Read [connection guidance](../../Docs/EffectCraft.md), root AGENTS and the active measured scene plan. The user opens the app. Resolve local executable paths and the chosen bridge from workspace configuration; never assume a port or a blank window belongs to this project.

Before mutation, verify listener/process/version, loaded native path, dirty state and render queue. Preserve unsaved work in a new checkpoint. Do not interrupt another render or replace another project's source. Discover supported commands and parameter schemas from the installed CLI; use CLI/live APIs, not desktop clicks or native JSON rewriting.

Build editable layers for the user's chosen style. Follow [Scene planning](../../Docs/Scene_Planning.md) and [Motion](../../Docs/Visual_and_Motion.md). Test uncertain app behaviors in a focused proof: null opacity propagation, descendant lifetimes, media imports, easing and audio routing. Check transformed bounds and stacking on rendered frames, not only source properties.

Inspect actual text and timing: exclusive typing states, aligned caption highlights, heading entrances/holds/exits, intentional visual causality and clean handoffs. Keep cursor interactions purposeful if the video uses them. Keyframe counts are not evidence of quality.

Queue only the intended composition/output; preserve older exports and queue history. Wait for native completion and save its receipt. Probe/decode the actual file, inspect corrected encoded frames and review playback/audio as available. Follow [QA](../../Docs/QA_and_Export.md). Deliver native source, export and evidence; report remaining subjective review explicitly.
