# Start here

1. Follow [README](README.md) for setup, then [AGENTS](AGENTS.md) for operating rules.
2. Check [HANDOFF](HANDOFF.md). No video is commissioned by this template.
3. Complete tool readiness using [tools](tools/README.md). Leave creative decisions to the user.
4. On a video request, run `python scripts/new_project.py` to create the next unused project. Fill its brief and status.
5. Continue through [Workflow](Docs/Workflow.md). Update HANDOFF with the active project and next concrete step.
