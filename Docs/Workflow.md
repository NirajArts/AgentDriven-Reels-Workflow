# Production workflow

| Stage | Output required |
| --- | --- |
| Research | User brief, supported claims, sources and content constraints |
| Script | Exact spoken words, intended delivery, on-screen actions and user review |
| Narration | Selected recording/take with measured duration and usage record |
| Independent timing | Raw transcription plus reviewed word times from actual audio |
| Measured shot plan | Dialogue cues, start/end frames, actions, headings, transitions and sound |
| Verify | Claims, inputs, tool readiness, timing feasibility, permissions and deliverable promises |
| Implement | Versioned editable source; inspect a short visual proof before expanding |
| Inspect and fix | Actual-output evidence, issues, corrected versions and rechecks |
| Final export | Native completion, media probe, full decode and final-output review |
| Packaging | Cover/thumbnail, caption, subtitles, credits, manifest and any tested deliverable |

For a silent video, replace narration/word timing with explicitly editorial timings. For existing recorded narration, skip synthesis and measure that recording. Estimates never become measured evidence merely because the plan was approved.

Establish a visual direction from the user's brief, prove a short representative section and carry accepted principles through the complete video. Vary composition without losing continuity. A visual should explain its sentence, not merely display a related label. For demonstrations, make actions reproducible and show their real results; label explanatory interface illustrations.

Script or audio changes invalidate affected timings, captions and scenes. Preserve unaffected accepted work. Record statuses as planned, ready, in progress, checked, partial or pending, with evidence. Do not treat scene, keyframe or sound-cue counts as quality scores.
