# Sound design

Choose sound density and music for the user's genre and tone. Narration leads where present. Keep original voice, sound effects and music as separate editable sources; track licenses and credits.

| Event | Possible sound role |
| --- | --- |
| Click/toggle/selection | Short precise interaction tick |
| Object transfer | Restrained movement/air/slide accent |
| Landing/reveal | Tap, pop or small impact |
| Typing | Brief texture synchronized to visible bursts |
| Confirmed result | Distinct confirmation after the visible result |
| Major transition | Stronger accent, bed change or intentional silence |

These are options, not a requirement for every move. Place cues against actual event frames in [Audio cues](../Templates/Audio_Cues.csv). Avoid repetitive whooshes and masking consonants. Trim empty onsets/tails and use fades where needed. Choose gains by listening to the actual mix; there is no universal number that guarantees balance.

Check clipping, tails, synchronization and intended silence numerically, then listen continuously. If listening is unavailable, record subjective mix review as pending.
